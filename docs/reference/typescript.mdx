### League

One League's public reads: players, ratings, Rosters, schedules, results and shop inventory. Reads need no key and are cached for a minute as the API asks; with the League's own developer key they draw on the plan's allowance instead of the per-address limit. Get one from `heir.league("nacl")`, by vanity name or Discord server ID.
