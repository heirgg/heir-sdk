Package: `heir` · Import: `github.com/heirgg/heir-sdk/go`

Package heir is the official Go client for the Heir public API: League players, ratings, Rosters, schedules, results and shop inventory, fixture eligibility checks, and stat submission.

```go
client := heir.NewClient(heir.WithAPIKey(os.Getenv("HEIR_API_KEY")))
nacl := client.League("nacl")
answer, err := nacl.Player(ctx, "mordhau", "A1B2C3D4E5F67890", nil)
```

Reads work without a key. Eligibility checks and stat submission need the League's developer key. The types in types\_\*.gen.go are generated from the API's OpenAPI documents in ../spec by `go generate`.

### APIError

APIError is an answer from the API that was an error. Code is the stable code to branch on (`rate-limited`, `league-not-found`, `rejected`, ...), Message a sentence for a person whose wording can change. StatusCode is the HTTP status and RetryAfter, on a 429, how long the API asked you to wait (zero when it did not say).

```go
var apiErr *heir.APIError
if errors.As(err, &apiErr) && apiErr.Code == "league-not-found" { ... }
```

for roster, err := range page.All(ctx) {
	if err != nil { return err }
	fmt.Println(roster.Name)
}

type Page[Item any, Body any] struct {

}
