# README banner

`readme-banner.png` is the 2172 × 724 raster banner used by the root README. It was generated with the built-in image-generation tool on 30 October 2026, using Heir's current crown app icon as the brand reference. The generated image was visually checked for legibility and the crown silhouette, then copied into this repository.

## Generation prompt

Create a new panoramic banner, approximately 3:1 aspect ratio (1536x512 or larger), using the attached Heir app icon as the brand reference. Preserve the recognizable crown silhouette: three sharp points, center point tallest, broad flat base and a separate thin horizontal bar beneath. Integrate that crown as a refined gold emblem, not inside an app icon circle. Brand palette from the existing product: nearly black warm charcoal #0e0e0c, warm gold #f5b83d, ivory white type. Editorial, precise, technical, understated. Rich dark matte background with very subtle thin geometric connection paths and sparse small nodes suggesting developer integrations; restrained gold illumination, clean open space, no busy circuitry. One unified composition with generous margins, elegant visual hierarchy, crown emblem alongside clearly readable title. Text exactly: "Heir SDK" as the large title, and "TypeScript  ·  Python  ·  Go" as a smaller supporting line. No additional slogan or words. Typography crisp, sophisticated modern sans-serif, large enough to read at GitHub README width. No screenshots, code blocks, buttons, fake UI, mascot, stock photos, lens flare, neon rainbow, watermarks or extra logos. Produce a polished finished raster banner, opaque background, not a mockup of a webpage.
